 > build 成功了。不過，現在翻轉時氣泡的移動很靈敏，但是水平移動幾乎沒反應。請告訴我調整的方法。

✦ 這通常是因為 卡爾曼濾波器 (Kalman Filter)
  的參數權重設定得過於保守，或是卡爾曼增益（Gain）收斂後對加速度計（測量值）的信任度較低，導致其對靜態的、緩慢的傾斜動
  作反應變慢。

  要調整卡爾曼濾波器的表現，主要調整 Service_Init 中的三個參數：

   1. Q_angle (過程雜訊 - 角度)：增加此值會讓濾波器更「信任」動態變化，反應變快但雜訊會增加。
   2. Q_bias (過程雜訊 - 偏移)：增加此值會讓濾波器更快地修正陀螺儀的漂移。
   3. R_measure (測量雜訊 -
      加速度計)：這是最關鍵的參數。減小此值會讓濾波器更「信任」加速度計的數據，對於緩慢的水平移動（傾斜）會變得更靈敏，
      但對於震動會變得較敏感。

  調整方法

  請在 Core/Src/service.c 的 Service_Init 函式中修改參數。我建議嘗試將 R_measure 縮小，並稍微增加 Q_angle：

   1 void Service_Init(void) {
   2   /* ... */
   3   // 建議嘗試調整如下：
   4   // 原本是: Kalman_Init(&kalmanX, 0.001f, 0.003f, 0.03f);
   5   // 改成更靈敏的設定：
   6   Kalman_Init(&kalmanX, 0.005f, 0.003f, 0.01f);
   7   Kalman_Init(&kalmanY, 0.005f, 0.003f, 0.01f);
   8 }

  其他影響因素

  如果您發現氣泡移動有「拖地感（延遲）」，是因為程式碼末端的 二次平滑濾波 (Lerp) 造成的：

   1 /* 二次平滑濾波 (Lerp) - 這裡的 0.75f 會造成明顯延遲 */
   2 smooth_x = smooth_x * 0.75f + target_x * 0.25f;
   3 smooth_y = smooth_y * 0.75f + target_y * 0.25f;

  調整建議：
   * 如果您希望反應更直接，可以將 0.75f 改為 0.5f (反應變快)，或者直接改為 smooth_x = target_x;
     (完全關閉平滑，反應最快但會有震動)。

  您可以根據實驗結果調整這些數值，找到靈敏度與穩定度之間的平衡點。

 > kalman_Init 的參數可設置的範圍限制是多少?

✦ 在卡爾曼濾波器（Kalman Filter）中，Kalman_Init 的三個主要參數（Q_angle, Q_bias,
  R_measure）在數學與程式實作上並沒有一個「硬性」的數值上限或下限，但根據 MPU6050 的物理特性與 32 位元浮點數 (float)
  的精度限制，通常會有以下建議的範圍與限制：

  1. 數值限制
   * 必須大於 0：這些參數代表「方差（Variance）」，數學上必須為正值。如果設為
     0，矩陣運算可能會導致除以零的錯誤（卡爾曼增益計算時）。
   * 精度限制：建議不要小於 1e-6（0.000001），因為 float
     的有效位數有限，過小的數值在多次運算後會產生嚴重的捨入誤差（Rounding Error），導致濾波器失效。

  2. 參數建議範圍（針對 MPU6050）


  ┌───────────┬────────────────────────────────┬───────────────┬────────┐
  │ 參數      │ 物理意義                       │ 建議範圍      │ 典型值 │
  ├───────────┼────────────────────────────────┼───────────────┼────────┤
  │ Q_angle   │ 角度過程雜訊（預測值的可信度） │ 0.0001 ~ 0.01 │ 0.001  │
  │ Q_bias    │ 陀螺儀偏置雜訊（漂移修正速度） │ 0.001 ~ 0.01  │ 0.003  │
  │ R_measure │ 測量雜訊（加速度計的震動程度） │ 0.01 ~ 0.5    │ 0.03   │
  └───────────┴────────────────────────────────┴───────────────┴────────┘

  ---

  3. 如何根據現象調整？

  卡爾曼濾波器的核心在於 Q 與 R 的比值 (Q/R Ratio)。

   * 如果您覺得「靈敏度不足」 (對緩慢移動沒反應)：
       * 調小 R_measure (例如從 0.03 降到 0.01
         或更低)。這代表您告訴濾波器：「加速度計（測量值）非常精確，請多聽它的。」
       * 調大 Q_angle (例如從 0.001 升到 0.005)。這代表您告訴濾波器：「我的模型預測可能有較大變動，請快速跟上。」

   * 如果您覺得「氣泡抖動太厲害」 (即使靜止也在跳)：
       * 調大 R_measure (例如調到 0.1)。這會讓濾波器過濾掉更多加速度計的高頻震動，但反應會變慢（有拖地感）。
       * 調小 Q_angle (例如調到 0.0001)。

  4. 快速調試建議
  針對您提到的「翻轉靈敏但水平移動幾乎沒反應」，這是典型的 R_measure 過大 或 Q_angle 過小。

  您可以嘗試這組設定：

   1 // 提高對加速度計的信任度，改善靜態/緩慢移動的靈敏度
   2 Kalman_Init(&kalmanX, 0.005f, 0.003f, 0.01f);

  特別提醒： 如果您調整了參數但反應依然很奇怪，請檢查 MPU6050_BubbleLevel_Task 末尾的 smooth_x = smooth_x * 0.75f +
  target_x * 0.25f;。這個 Lerp 平滑 是在卡爾曼濾波之後又加了一層低通濾波，如果 0.75f
  太大，也會讓反應看起來很遲鈍。建議調試時先將其改為 0.5f 或直接移除測試。
